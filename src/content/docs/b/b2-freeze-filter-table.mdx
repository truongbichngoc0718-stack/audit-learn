<Eyebrow>Freeze Panes</Eyebrow>
## Giữ dòng tiêu đề đứng yên
<kbd>Alt</kbd> → <kbd>W</kbd> → <kbd>F</kbd> → <kbd>F</kbd>: bấm **lần lượt** từng phím, không cần giữ. Excel cố định mọi dòng **phía trên** và mọi cột **bên trái** ô đang chọn.

| Chọn ô | Kết quả |
|---|---|
| A5 | Cố định dòng 1–4 (tiêu đề ở dòng 4). Lựa chọn cho sheet 01 GL |
| E5 | Cố định dòng 1–4 **và** cột A–D (STT, ngày, số chứng từ) khi cuộn ngang |
| Bỏ freeze | Bấm lại đúng tổ hợp này |

<Eyebrow>Filter</Eyebrow>
## Bật bộ lọc và lọc nhanh
<kbd>Ctrl</kbd> + <kbd>Shift</kbd> + <kbd>L</kbd>: bật / tắt filter. Đứng ở **dòng tiêu đề** (dòng 4) trước khi bấm. <kbd>Alt</kbd> + <kbd>↓</kbd> ở ô tiêu đề: mở menu lọc, gõ ngay vào ô Search.

<Eyebrow>Vẽ bảng</Eyebrow>
## Table và kẻ viền
<kbd>Ctrl</kbd> + <kbd>T</kbd>: chuyển vùng dữ liệu thành **Table** (tự có filter, sọc màu, tự mở rộng, công thức tự kéo cả cột). Tick *My table has headers*.

| Phím tắt kẻ viền | Tác dụng |
|---|---|
| <kbd>Alt</kbd> → <kbd>H</kbd> → <kbd>B</kbd> → <kbd>A</kbd> | All Borders |
| <kbd>Ctrl</kbd> + <kbd>Shift</kbd> + <kbd>&amp;</kbd> | Viền ngoài |
| <kbd>Ctrl</kbd> + <kbd>Shift</kbd> + <kbd>_</kbd> | Xóa viền |
| <kbd>Ctrl</kbd> + <kbd>1</kbd> | Format Cells |

**Dùng ở đâu trong kiểm toán:** lọc cột *Loại CT* = PKT và cột *Ngày nhập hệ thống* để lập danh sách bút toán tay ([Bài 3.7](/a/3/a3-7-but-toan-tay-blq/)).

# STYLE_C: chuẩn nhánh C · ACCA AA

Bổ sung cho BISC_STYLE v1.0 (không thay thế). BISC_STYLE §1 (bộ lọc 6 chu trình Biscore) **không áp dụng** cho nhánh C: phạm vi nhánh C = syllabus ACCA AA, nguồn = slide + checkpoint BISC. Các mục còn lại của BISC_STYLE áp dụng khi không mâu thuẫn với dưới đây.

## 1. Phạm vi & nguồn
- Nguồn duy nhất: `source/library/acca-aa/` (slide `slide/chNN.md`, checkpoint `checkpoint/cpN.md`). Khi slide là sơ đồ/ảnh (đáp án Activity, bảng), xem ảnh trang gốc trước khi viết.
- Nội dung slide và checkpoint: **giữ nguyên văn** câu hỏi, đáp án, model answer, examiner's notes; ghi nguồn đề (`Source: Dec 2024 Exam Q3(a)`) đúng như checkpoint.
- Lời giảng nối giữa các khối: viết lại ngắn gọn từ slide, không thêm kiến thức ngoài slide/checkpoint. Thêm ngoài → khối `Extended` + căn cứ (ISA số đoạn).

## 2. Ngôn ngữ & giọng văn
- **Toàn bộ tiếng Anh** (UK spelling như đề ACCA: recognise, organisation, programme).
- Gọi người học "you". Câu ngắn, chủ động; in đậm chữ quyết định ("book → floor **=** existence").
- Thuật ngữ đúng ISA/IFRS; viết tắt dùng được: FS, TB, GL, GDN, GRN, NRV, PPE, NCA, ToC, TCWG, KAM, EOM, YE, IAS, IFRS, ISA.
- Chuẩn mực dạng nhãn: "ISA 500 · ISA 315". Đối chiếu VSA chỉ khi bài nhánh A liên quan (dòng "Link to Branch A").

## 3. Khuôn bài chương (loai: acca)
Header tự sinh: "Part D · Audit evidence / Chapter 7" · "Chapter 7 — {short} · n min" · takeaway 1–2 câu.
1. **Learning outcomes** (≤ 5 gạch, động từ: explain, distinguish, apply, describe).
2. Khối khái niệm: Eyebrow → H2 câu hành động → nội dung slide → ≥ 1 tương tác có lời dẫn ("Click…", "Build a procedure…").
3. **Exam angle**: dạng câu hỏi · cách làm · bẫy (lấy từ checkpoint tương ứng).
4. **Activity** từ slide: giữ nguyên đề, đáp án trong khối ẩn.
5. ⚠️ **If you skip this** (1 câu hậu quả) + 🔑 **Key principle** (1 câu).
6. **Quick check** (bấm xem đáp án) → "Link to Branch A" (nếu có) → Notes.
Thời lượng: một trang = một chương slide, ≤ 15 phút (≈ 250 từ + 1 tương tác cho mỗi 3 phút); chương dài hơn tách thành bài con (7a, 7b…).

## 4. Khuôn trang Checkpoint (loai: checkpoint)
1. Exam structure (bảng gọn) → 2. Knowledge revision (mindmap/bảng tương tác) → 3. Exam techniques (dạng câu · cách làm · bẫy; Common mistakes) → 4. Practice MCQ (chấm từng câu, giải thích) → 5. Constructed response (viết → model answer theo ý → tự chấm) → 6. Mock test (đồng hồ, khóa đáp án đến khi nộp) → Notes.
Điểm practice, mock, CR lưu vào trang Tiến độ.
